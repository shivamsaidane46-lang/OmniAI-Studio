# OmniAI Studio

Official OmniAI Studio website.

## Stack

- Next.js 16
- React 19
- TypeScript
- CSS

## Local development

```bash
npm install
npm run dev
```

Then open `http://localhost:3000`.

## Challenge workflow

The 30-day challenge is designed so new workflows can be added without rebuilding the website. Project data will be expanded as each daily workflow is completed.
