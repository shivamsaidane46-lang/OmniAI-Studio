## The problem

Invoices arrive in different layouts and formats. A useful automation must handle variability instead of assuming every document looks the same.

## System approach

1. Receive an invoice file.
2. Extract fields and line items with document processing and AI.
3. Validate the result against a predictable schema and business rules.
4. Route clean data to the next system or flag uncertain documents for review.
